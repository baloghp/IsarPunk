## 1. Trigger — Windows 10 security cliff

- Mainstream support already ended (Oct 2025). Consumer **ESU** runs through **12 October 2027** — runway to sow, not panic.
- Still-usable machines risk landfill or ransomware after the cliff — especially seniors’ PCs.
- Angles to hit lightly: e-waste, security, elderly exposure → *young punks save Oma*.

*(Optional research aside if asked: US ESU / e-waste parallels — don’t derail the room.)*

---

## 2. We have an alternative: Linux / FOSS

Myth-bust block (confidence, not a full install class):

1. Short Linux / FOSS story  
2. Distros exist — pick a friendly one for demos  
3. **Yes, it is usable** — AI can and should help you learn  
4. **Yes, it can game**  
5. **Yes, it can do heavy jobs** (e.g. video editing)  
6. Jump on FOSS culture  
7. You can still use Microsoft Office apps if you *really* need them  

---

## 3. Why save old PCs (circular + economics)

- Computing prices spike: GPU hikes, RAM scarcity  
- Skills to revive hardware are valuable — and today even profitable  
- Circular reuse beats “buy new for the cliff”

---

## 4. What we ask / how we help

**Ask of the room**

- Talk to family (Oma / Opa / neighbours) about the cliff  
- Don’t bin a working machine — bring it to a repair partner  
- Try a Live USB / first boot when safe to do so  

**How we help**

- Workshop confidence + take-home path  
- Partner list: repair shops & cafés in the city ([CircularCity Map](https://circular-munich.com/circularcitymap/) + IsarPunk cheat sheet)  
- We do **not** promise “we finish Oma’s PC at scale” — hubs finish the deep work
