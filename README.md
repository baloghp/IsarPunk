# IsarPunk

**Hack your life / Save Oma**

Munich youth & community project turning Windows 10 End-of-Life e-waste into open-source upcycling, family digital security, and hands-on workshops.

## What this is

By October 2026, Windows 10 Extended Security Updates end in the EU. Millions of still-usable PCs risk landfill or ransomware exposure — especially machines used by seniors.

IsarPunk is a seed initiative to:

1. **Save Oma** — help families migrate to Linux / FOSS instead of throwing hardware away  
2. **Upcycle** — turn discarded machines into fast, useful tools  
3. **Build** — teach Gen Alpha to run their own network shield, media, cloud, and home lab  

Project team: 3 volunteers · seed budget: €1,000 · home base: Munich
