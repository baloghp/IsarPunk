## 0. Card ID convention

Every card has a permanent ID (`B4`, `O3`). Use IDs when logging dot counts so data stays comparable across all six workshops even if wording changes. **If a card's meaning changes, give it a new ID** — do not silently reuse.

Nothing has been printed or run yet, so IDs are still free to move. **Freeze them after the first playtest.**

## 1. Set A — Layer sort (primer)

**Rows on the table:** `GERÄT` · `BETRIEBSSYSTEM` · `APP`
**Job:** make the word *Betriebssystem* mean something before anyone holds an opinion about one.
**Copies:** 4 (one per team of 3)

| ID | Card (DE) | EN | Correct row | Note |
|----|-----------|----|-------------|------|
| A1 | Laptop | Laptop | Gerät | Easy anchor |
| A2 | Smartphone | Smartphone | Gerät | Easy anchor |
| A3 | Spielekonsole | Games console | Gerät | *optional — drop if short on time* |
| A4 | Windows | Windows | Betriebssystem | Often misplaced as *Gerät* ("the PC is a Windows") |
| A5 | **Android** | Android | Betriebssystem | **Leave visible.** Sets up the flip at 24 min |
| A6 | iOS | iOS | Betriebssystem | Some kids won't know the word — they know *iPhone*. Let the team argue |
| A7 | macOS | macOS | Betriebssystem | |
| A8 | Linux (Tux) | Linux (Tux) | Betriebssystem | Use the penguin, not the word alone |
| A9 | Word | Word | App | |
| A10 | Chrome | Chrome | App | **Best discussion card** — ChromeOS exists, so "both" is a smart wrong answer. Reward the reasoning |
| A11 | Fortnite | Fortnite | App | |
| A12 | TikTok | TikTok | App | |
| A13 | WhatsApp | WhatsApp | App | *optional* |
| A14 | Minecraft | Minecraft | App | *optional — Fortnite already covers games* |
| A15 | Steam | Steam | App | Second setup for the flip: SteamOS exists and the Steam Deck runs Linux. Also reappears at both stations |

**Facilitator conduct in this block:** circulate, ask *"warum habt ihr die da hingelegt?"*, and **correct nothing**. The sort is diagnostic, not a quiz. If a team asks for the answer, say you'll come back to it — you will, at 24 minutes.

⚠️ **Logos:** fine for classroom use. Revisit before publishing the deck under the repo's CC BY licence — a text-only variant may be needed for the train-the-trainer pack.

## 2. Set B — Opinion cards

**Zones:** `STIMMT` · `UNSICHER` · `STIMMT NICHT`
**Copies:** 4 (one per team of 3–4)
**Dealt in two lots of five.** All ten cards is the default in a 2-hour slot; drop B3 and B7 for an 8-card variant if the school only gives 90 minutes. No answers given in this block — every card is answered later by a machine or a mission.

### Lot 1 — Betriebssysteme

| ID | Card (DE) | EN | Answered by |
|----|-----------|----|-------------|
| B3 | Linux ist nur für Hacker und Programmierer. | Linux is only for hackers and programmers. | The flip (Android) + both stations |
| B4 | Wenn Windows keine Updates mehr bekommt, funktioniert der Computer nicht mehr. | If Windows stops getting updates, the computer stops working. | **Mission 1 news** — the key card for the cliff |
| B5 | Ein Betriebssystem muss man kaufen. | You have to pay for an operating system. | Sheets F1 and F2, last item on each |
| B6 | Ein anderes Betriebssystem zu installieren macht den Computer kaputt. | Installing a different operating system breaks the computer. | **Station A** — two distros, nothing installed |
| B10 | Ich habe Linux noch nie benutzt. | I have never used Linux. | **The flip card** (§5.5) |

### Lot 2 — Alte Geräte

| ID | Card (DE) | EN | Answered by |
|----|-----------|----|-------------|
| B1 | Ein Laptop von 2015 ist eigentlich Elektroschrott. | A laptop from 2015 is basically e-waste. | Both stations — the hero machine *is* from 2015 |
| B2 | Auf Linux kann man nicht richtig zocken. | You can't really game on Linux. | Station A (Bazzite) + F2 — with the anti-cheat caveat |
| B7 | Ein Tablet kann alles, was ein Laptop kann. | A tablet can do everything a laptop can. | F2 — weakest link, see note |
| B8 | Nur ein Profi kann einen alten Computer wieder brauchbar machen. | Only an expert can make an old computer useful again. | Stations + Mission 2 |
| B9 | Omas alter PC kann weg. | Oma's old PC can go. | Mission 2 |

**B4 is the most important card in the deck.** The honest answer is nuanced — the computer keeps working, it just stops being *safe*. That distinction is the entire Win10 story, and it's why B4 is answered in Mission 1 rather than at a station.

**B7 is the deck's weakest card** — F2 only partly answers it. Keep it for now because it opens the "your tablet is a computer with a locked-down OS" thread, which is a FOSS-sovereignty seed for older groups. **Cut it first** along with B3 when you need the 8-card variant.

**Deck audit rule:** every card must be answered by a named later block. A card with no answer is dead weight — cut it.

## 3. Set C — Mission 1 actions (the Win10 news)

**Board:** ONE shared A2 for the whole room, with endings **O1–O3** already laid down the right-hand edge.
**Dots:** one per student, colour 1, **on action cards only**.
**Copies:** 1 set per workshop (consumable).

| ID | Card (DE) | EN | Tier |
|----|-----------|----|------|
| C1 | Frag Oma, Opa oder eine ältere Person, welches Windows auf ihrem PC läuft. | Ask a grandparent or older relative which Windows is on their PC. | Talk |
| C2 | Erklär jemandem zu Hause, was im Oktober 2027 passiert. | Explain to someone at home what happens in October 2027. | Talk |
| C3 | Schau bei einem Computer in der Familie nach, ob er noch Updates bekommt. | Check one family computer: is it still getting updates? | Check |
| C4 | Erzähl es drei Leuten außerhalb dieses Raums. | Tell three people outside this room. | Talk |
| C5 | Finde heraus, ob ein PC in der Familie überhaupt Windows 11 kann. | Find out whether a family PC could even run Windows 11. | Check |
| C6 | Zeig jemandem einen Live-USB-Stick — auf dem Computer wird nichts verändert. | Show someone a Live USB — nothing changes on their computer. | Do ⚠️ |
| C7 | Frag eine KI, was man mit diesem alten PC machen kann. | Ask an AI what can be done with this old PC. | Learn |
| C8 | Such ein YouTube-Tutorial und schau es dir an. | Find a YouTube tutorial and watch it. | Learn |
| C9 | Frag jemanden in der Schule, der sich mit Computern auskennt. | Ask someone at school who knows about computers. | Learn |
| C10 | **Sichere zuerst Omas Fotos.** | **Back up Oma's photos first.** | Do — safety |
| C11 | Bring den PC in einen Repair-Shop und frag, was möglich ist. | Take the PC to a repair shop and ask what's possible. | Do → shop |

**C7–C9 are the self-teaching routes.** They matter because the narrative outline explicitly says *AI can and should help you learn* — this is where that promise becomes an action a student can pledge.

**C10 is a prerequisite card, not an optional one.** In the arrow phase, ask which actions should have C10 pointing into them. Any chain that installs or wipes anything and skips C10 is a chain that loses someone's photos.

**C11 is the bridge to the partners** — a dot here is a student who needs the list, so name a shop to them and make sure they leave with the take-home package.

⚠️ **C6 has a budget consequence.** It only works if the student has a stick. Twelve students × six workshops at ~€5 is ~€360 of a ~€1,000 seed. This is not a hardware giveaway in the sense of D7 (that decision was about laptops), but it is real money that isn't budgeted. **Open question — see §8.**

## 4. Set D — Mission 2 actions (household e-waste)

**Boards:** one A2 **per team** of 3–4, with the **full ending set O1–O8** down one edge. Teams draw their own arrows.
**Dots:** one per student, colour 2, on their own team's board, **action cards only**.
**Copies:** 4 sets per workshop (consumable).

**Do not print the path labels on the cards.** The grouping is what the teams discover.

| ID | Card (DE) | EN | Path |
|----|-----------|----|------|
| D1 | Such in der Wohnung nach einem Gerät, das niemand mehr benutzt. | Hunt through the house for a device nobody uses. | Find |
| D2 | Frag Nachbarn oder Oma, ob noch was im Schrank liegt. | Ask a neighbour or Oma if something is sitting in a cupboard. | Find |
| D3 | Gib einen wiederbelebten Laptop an ein jüngeres Geschwisterkind weiter. | Pass a revived laptop on to a younger sibling. | Keep in family |
| D4 | Richte Omas PC so ein, dass er sicher bleibt. | Set up Oma's PC so it stays safe. | Keep in family |
| D5 | Probier einen Live-USB-Stick an einem Gerät, das du benutzen darfst. | Try a Live USB on a device you're allowed to use. | Revive ⚠️ |
| D6 | Installiere Linux — zusammen mit einem Erwachsenen. | Install Linux — together with an adult. | Revive ⚠️ |
| D7 | Bau mehr RAM oder eine SSD ein. | Add more RAM or an SSD. | Revive ⚠️ |
| D8 | Bring es zu einem Repair-Shop oder Repair-Café von unserer Liste. | Take it to a repair shop or Repair Café from our list. | Repair ⚠️ |
| D9 | Mach daraus eine Retro-Spielekonsole. | Turn it into a retro games console. | Repurpose |
| D10 | Mach daraus eine Mediabox für den Fernseher. | Make it a media box for the TV. | Repurpose |
| D11 | Nutze einen alten Bildschirm weiter. | Reuse an old screen. | Repurpose |
| D12 | Mach daraus einen Computer nur für Hausaufgaben. | Make it a computer just for homework. | Repurpose |
| D13 | Verkauf es oder verschenk es, statt es wegzuwerfen. | Sell it or give it away instead of binning it. | Pass on |
| D14 | Bring ein wirklich totes Gerät zum Wertstoffhof — nicht in den Hausmüll. | Take a truly dead device to the Wertstoffhof — not the household bin. | Recycle |
| D15 | Verkauf brauchbare Einzelteile (RAM, Festplatte). | Sell usable parts (RAM, hard drive). | Pass on — *optional, advanced* |

### ⚠️ Safety rules — printed on every Revive and Repair card (D5–D8)

> 1. **Lösche nie einen Computer, der nicht dir gehört, ohne das OK der Besitzerin oder des Besitzers.**
> 2. **Vorher Backup. Wenn du unsicher bist — bring es in den Laden.**

*(EN: Never wipe a computer that isn't yours without the owner's yes. Back up first — if unsure, take it to the shop.)*

### Arrow prompts (read aloud, also printed on the team board)

- **Welche Karten müssen vor anderen passieren?** — Which cards have to happen before others?
- **Welcher Weg hält am meisten aus dem Müll?** — Which path keeps the most material out of the bin?
- **Welche Karten brauchen einen Erwachsenen? Welche brauchen einen Laden?** — Which cards need an adult? Which need a shop?
- **Wo landet euer Gerät am Ende?** — Where does your device end up? *(→ Set O)*

The third prompt is how **D8 becomes an answer the team found**, rather than an address handed to them. The fourth is what makes the board resolve.

✅ **D8 is live.** Two Munich repair shops have signed [listing consent](../Artifacts/Partner%20Listing%20Consent.md) (Sep 2026), with more expected.

**D8 is where partners get named.** There is no separate partner-list block — see format doc §5.8. Carry a one-line crib of which shops to name, and prefer the one nearest this school.

## 5. Set O — Ending cards

**One set, used at two scales.** Mission 1 uses **O1–O3** only; Mission 2 uses **all eight**. That repetition is the point — Mission 2 revisits endings the room already met, then extends them.

**Placement:** laid down one edge of every board **before** the action cards are dealt, so the room knows from the start that actions have to land somewhere.
**No dots ever go on an ending.** You can pledge an action; you cannot pledge an outcome.

| ID | Card (DE) | EN | Mission | Note |
|----|-----------|----|---------|------|
| O1 | Der PC läuft mit Linux und wird weiter benutzt. | The PC runs Linux and is still being used. | 1 + 2 | The FOSS ending |
| O2 | Ein Repair-Shop hat ihn repariert oder Linux installiert. | A repair shop fixed it or installed Linux. | 1 + 2 | **The referral ending.** When a team's arrow reaches this, name a real shop on the spot (format doc §5.8) |
| O3 | **Nichts passiert. Der PC bleibt online — und unsicher.** | **Nothing happens. The PC stays online — and unsafe.** | 1 + 2 | **Null ending.** The stakes, without a lecture |
| O4 | Jemand anders benutzt ihn jetzt — verkauft oder verschenkt (z.B. eBay). | Someone else uses it now — sold or given away (e.g. eBay). | 2 | |
| O5 | Daraus ist etwas Neues geworden — Retro-Konsole oder Mediabox. | It became something new — retro console or media box. | 2 | |
| O6 | Die Materialien wurden richtig verwertet. | The materials were properly recovered. | 2 | The honest-recycle ending — not a failure |
| O7 | **Er liegt weiter im Schrank.** | **It's still in the cupboard.** | 2 | **Null ending** for e-waste |
| O8 | Jemand in der Familie hat jetzt einen Computer, der vorher keinen hatte. | Someone in the family now has a computer who didn't have one before. | 2 | The *Save Oma* ending |

**How the payoff works.** After the dots are placed, trace the arrows from dotted actions to endings and read the board back: *"Das sind unsere Punkte. Wo landet Omas PC also?"*

If no chain of dots reaches a good ending, then **O3** (or **O7**) is the answer. State it flatly and move on — no moralising. The board said it, not the facilitator.

**O6 is deliberately not a failure state.** A genuinely dead device going to the Wertstoffhof instead of the household bin is a win, and framing it as one prevents the demoralisation the German repair-in-school studies warn about when a machine won't revive.

**Log which endings the dots reach**, per workshop. That is the format's own output measure (format doc §12).

## 6. Set E — Confidence statements

**Format:** A4 landscape, one statement per sheet, on the wall. Floor zones: `JA` · `UNSICHER` · `NEIN`.
**Deliberately different zone labels from Set B** so the metric never gets confused with the belief harvest.
**Used twice, identically:** 0–3 min and 80–88 min.

| ID | Statement (DE) | EN |
|----|----------------|----|
| E1 | Ich könnte jemandem erklären, was ein Betriebssystem ist. | I could explain to someone what an operating system is. |
| E2 | Ich könnte Linux an einem Computer ausprobieren, ohne ihn kaputt zu machen. | I could try Linux on a computer without breaking it. |
| E3 | Ich wüsste, was man mit einem alten Computer macht, den niemand mehr benutzt. | I would know what to do with an old computer nobody uses. |
| E4 | Ich könnte jemandem in meiner Familie mit einem alten PC helfen. | I could help someone in my family with their old PC. |
| E5 | Ich weiß, wo man in München ein Gerät zur Reparatur bringen kann. | I know where in Munich you can take a device for repair. |

These are **self-efficacy** ("I could"), not knowledge — that is what D5 in the minutes commits us to measuring. Never reword them between workshops or the six sessions stop being comparable.

**E5 is the canary card.** There is no standalone partner block any more, so E5 depends entirely on shops being named in-flight during Mission 2 plus the take-home package. If E5 doesn't move across the first two workshops, the in-flight naming isn't working and the partner beat has to come back as its own block.

Anonymous aggregate only: photograph the zones, count bodies, collect nothing.

## 7. Print & production spec

| Set | Size | Copies per workshop | Finish |
|-----|------|---------------------|--------|
| A | A6 (4 per A4) | 4 sets | Laminate once, reuse |
| B | A6 | 4 sets | Laminate once, reuse |
| **C** | A6, blank corner for dots | 1 set (11 cards) | Plain paper, consumable |
| **D** | A6, blank corner for dots | 4 sets (60 cards) | Plain paper, consumable |
| **O** | A6, visually distinct — different colour stock or a border | 1 × O1–O3 + 4 × O1–O8 (35 cards) | Plain paper, consumable |
| E | A4 landscape | 1 set | Laminate once, reuse |

**Consumable print run per workshop:** ~27 A4 sheets (C, D, O) plus 24 station sheets (F1/F2, one each per student).
**Also per workshop:** 5 × A2 poster sheets (1 Mission 1 + 4 Mission 2), ~26 dot stickers in two colours, markers per team.

**Why C, D and O are all consumables:** the boards stay with the teacher on the classroom wall, so every card taped to a board leaves the building. Laminating them would mean stripping five boards after each session and losing the photo evidence. Reprinting ~27 sheets is cheaper than that hassle.

**Set O must look different from the action cards** at a glance — coloured stock or a heavy border. Students need to see instantly that endings are not things you put a dot on.

## 8. Open questions

1. **Live USB sticks (C6, D5)** — lend a shared set, hand them out (~€360 across six workshops), or only point to a download guide? Not budgeted
2. **DE review** — every translation here is a draft. Needs a native speaker before it goes in front of a class
3. **Age band** — Set B and the primer are pitched at ~12–15. A 15–18 group may find the primer patronising
4. **Set A distro logo** — specific (Mint? Bazzite?) or generic Tux, given Station A now shows two distros
5. **Card backs** — blank, or IsarPunk logo? Logo costs double-sided printing on ~90 cards
6. **A15 Steam** — keep? It strengthens the flip and now pays off at Station A too
7. **Wertstoffhof (D14, O6)** — name a specific Munich location, or keep it generic?
8. **Is 11 + 15 action cards too many** for 12 and 22 minutes? First thing the playtest should answer
