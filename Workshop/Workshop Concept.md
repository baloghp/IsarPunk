## 1. Format idea

Derived from **Climate Fresk** pedagogy: cards in lots, the room discovers rather than receives, then action. A full Fresk wants ~3 hours; this is a Fresk-shaped **90 minutes** of content inside a **2-hour school slot**.

Both mission blocks are **path-building between fixed points**. The facilitator places a start on the left and the possible endings on the right; students build the route between them.

The two missions start differently on purpose:


| Mission           | Starts as                           | Why                                                           |
| ----------------- | ----------------------------------- | ------------------------------------------------------------- |
| **1 — Oma's PC**  | Someone else's concrete **problem** | Learn the mechanic on a shared board                          |
| **2 — Your goal** | A **goal** the team draws and owns  | Four different boards; finding a device is a step on the path |


Solve for another person first, then pick your own reason.

---



## 2. Design principles


| Principle                      | In the room                                             |
| ------------------------------ | ------------------------------------------------------- |
| **Belief first**               | Harvest what kids already think before giving facts     |
| **Discovery over lecture**     | Myth-busts are *found* on a real machine                |
| **Agency over doom**           | Bad news is always adjacent to an action block          |
| **No public wrong answers**    | Continuum placement — confidence is the KPI             |
| **Honest caveats**             | Name what does *not* work (anti-cheat, Office macros)   |
| **Actions have endings**       | Boards resolve into named outcomes — including inaction |
| **Partners named when earned** | Name the shop the moment a team's arrow needs one       |

## 4. The 90 minutes


| Min   | Block                                   | Mode                                         | Cards            |
| ----- | --------------------------------------- | -------------------------------------------- | ---------------- |
| 0–3   | Confidence **in**                       | Floor continuum, photographed                | Set E            |
| 3–6   | Hook                                    | Facilitator, short                           | —                |
| 6–12  | **Primer: layer sort**                  | Teams place logo cards                       | Set A            |
| 12–24 | **Opinion cards**                       | Teams place on continuum                     | Set B            |
| 24–26 | **The flip: you already use Linux**     | Whole room, no machines                      | —                |
| 26–44 | **Two stations, parallel** · swap at 35 | Hands on keyboards                           | Sheets F1 / F2   |
| 44–58 | **Mission 1: Oma's PC**                 | Path-building + dots                         | Sets S1, C, O    |
| 58–82 | **Mission 2: your goal**, two lots      | Path-building + dots · shops named in-flight | Sets S2–S5, D, H |
| 82–90 | Close: take-home + confidence **out**   | Continuum, mission line                      | Set E            |


**Never sacrifice:** the stations and Mission 2. Mission 1 teaches the path-building mechanic so Mission 2 needs no instructions.

### Buffer (in a 2-hour slot)

~30 minutes sit outside the 90 — expect leakage, not free time:


| Source                               | Realistic cost |
| ------------------------------------ | -------------- |
| Arrival, settling                    | 5–10 min       |
| Opinion cards overrun                | up to 5 min    |
| Mission 2 overrun                    | up to 5 min    |
| USB boot needs a second stick        | 2–5 min        |
| Packing up, boards on wall, goodbyes | 5–8 min        |


If none of that happens, use the expansions in §9.

## 5. Block-by-block



### 5.1 Confidence in (0–3)

Five statements on the wall (Set E). Floor zones: **JA / UNSICHER / NEIN**. Photograph the distribution.

Anonymous aggregate only — no names, no sheets. Matches the minimal-data stance in the [platform concept](../Engagement%20Platform/High-Level%20Concept.md).

### 5.2 Hook (3–6)

IsarPunk, Circular Munich e.V. We do **not** repair devices and we are not here to make anyone feel guilty.

Do not explain Linux yet. Do not assume *Betriebssystem* is understood.

### 5.3 Primer — layer sort (6–12)

Three rows on each table: **GERÄT · BETRIEBSSYSTEM · APP**. Teams place Set A.

Purpose: the word has to mean something before anyone holds an opinion about one. A definition slide would break *belief first*, so this is a sort, not a lecture.

Circulate, ask *"warum habt ihr die da hingelegt?"*, correct nothing. Leave the **Android** card visible on the OS row — setup for §5.5.

### 5.4 Opinion cards (12–24)

Teams place Set B on **STIMMT / UNSICHER / STIMMT NICHT**. Ten cards, two lots of five.

**No answers in this block.** Revisit at the close after the machines have answered them.

Most elastic block — if it runs long, take time from the buffer, not from Mission 2.

### 5.5 The flip (24–26)

Whole room, no machines.

*"Hände hoch, wer bei 'Ich habe Linux noch nie benutzt' auf STIMMT gelegt hat."* Then Android on the OS row, and the phones in their pockets. Android runs a Linux kernel. The Steam Deck is Linux.

They are not beginners. Split the room; send each half to a station.

### 5.6 Two stations, parallel (26–44)

Two groups of ~6, one facilitator each. Swap at ~35. Everyone holds a printed sheet and ticks along.


| Station               | Machine                        | Sheet | Job                                    |
| --------------------- | ------------------------------ | ----- | -------------------------------------- |
| **A — Flavours**      | Old hero laptop, USB sticks    | F1    | Distros exist, free, nothing installed |
| **B — Treasure hunt** | Second laptop, installed Linux | F2    | Find the software (myth-busts)         |


**Station A** boots **Linux Mint**, then **Bazzite**, live from sticks on the same old machine.

- The boot wait is content: *"gerade hat dieser Computer kein Betriebssystem — in einer Minute hat er eins."*
- Whichever distro is up when a group arrives, boot the other.
- Let students hold a stick.
- USB 2.0 on a 2015 machine: 1–2 min per boot. Pre-boot one distro if needed.

**Station B**

- Rotate the keyboard — a different student finds each item
- Find and tick only; launch **one** thing at the end
- State honest caveats when the item is found (see F2)

Win10 news has **not** been broken yet. Both stations are "look what this old thing can do."

### 5.7 Mission 1 — Oma's PC (44–58)

Break the news after eighteen minutes of optimism:

- Mainstream Windows 10 support ended 2025
- Consumer ESU runs to **12 October 2027**
- Roughly **28%** of Windows desktops are still on Windows 10 (StatCounter mid-2026 — say *"roughly"*; it measures web traffic, not installed machines)
- Those are mostly people like Oma

**One shared A2.** Facilitator sets both edges before dealing:

1. **Left — S1:** *"Omas PC läuft Windows 10. Sie weiß nichts von 2027."*
2. **Right — Set O** (six Oma endings): runs Linux safely · shop switched it · nothing happens / unsafe · buys a new PC she didn't need · falls for a scam · too scared to use it
3. **Challenge:** *"links ist das Problem. Rechts steht, wie es ausgehen kann. Baut den Weg."*
4. Deal Set C (14 actions) — live-USB chain, self-teaching routes, shop
5. Draw arrows from S1 through actions to an ending
6. One **dot** per student on the action they will do
7. Read the board: *"Das sind unsere Punkte. Wo landet Omas PC also?"*

Four of six endings are bad on purpose. If no chain reaches O1 or O2, one of the failure endings is the answer — state it flatly, don't moralise.

Shared board: everyone learns the mechanic once before Mission 2 scales it up.

### 5.8 Mission 2 — your goal (58–82)

One A2 **per team** of 3–4. Actions arrive in **two lots**.

1. **Each team draws a goal** (S2–S5): no device from home in the bin · family's digital life safer · build something from old stuff · everyone at home has a working computer. Frame e-waste lightly: laptop ≈ **2 kg**, desktop ≈ **8 kg**.
2. Place Set **H** (eight endings) down the right edge.
3. **Deal Lot 1** (D1–D11): find, diagnose, back up, revive, repair, pass on, recycle. Draw arrows. D1/D2 are usually the first move.
4. **Name shops in-flight** while circulating (below).
5. **Deal Lot 2** (D12–D17) as a reveal: *"und jetzt — was man daraus wirklich bauen kann."* Entertainment, security/privacy, own chat server, learn cards. Ending **H3** only becomes reachable now.
6. One **dot** per student on their team's board.
7. **Gallery walk** (2 min): *"Wer hat das gleiche Ende auf einem anderen Weg erreicht?"* No presentations.

If a room is struggling, give every team **S2** and run one shared question.

**H6 vs H8:** Wertstoffhof = win; household bin = failure. Same device, different outcome — reachable regardless of skill.

#### Naming partners

No standalone partner monologue. When a team's chain reaches **D8** or ending **H2**, name a real shop on the spot:

> *"Das hier braucht eine Adresse. Es gibt einen Laden in …"*

Full list goes home in the take-home package. Two shops already signed; facilitators need names and rough locations on a crib (§8). Prefer the shop nearest this school.

### 5.9 Close (82–90)

1. Hand out the **take-home package**: named partners, [CircularCity Map](https://circular-munich.com/circularcitymap/), every learn QR, blank *meine Mission* line. One sentence: *"alle Läden und alle Links stehen hier drauf."*
2. Students fill *meine Mission* from their own dot
3. Revisit two or three opinion cards — *"wer würde seine Karte jetzt verschieben?"*
4. Confidence continuum again (Set E), photographed
5. Boards **stay with the teacher, on the wall**

## 6. The dot mechanic

A dot is a **personal pledge**, not a vote. *"Das mache ich."*


| Rule                                                      | Why                                        |
| --------------------------------------------------------- | ------------------------------------------ |
| Dots only on **action** cards                             | You pledge an action, not an outcome       |
| Decide privately; place on a count of three               | First three dots otherwise decide the room |
| One dot per student per mission                           | Forces a choice                            |
| Two colours (Mission 1 / Mission 2)                       | Countable separately                       |
| Mission 1 = shared board · Mission 2 = one board per team | Learn together, then own the map           |
| Read the board before moving on                           | Dots + arrows *are* the answer             |


The mission is the whole board; the dot is your part of it. The student's copy is the blank line on the take-home sheet.

**What we get:** photos, dots per card ID, endings reached — across six workshops. Taxonomy the [engagement platform](../Engagement%20Platform/High-Level%20Concept.md) would need if un-parked.

**What we don't get:** proof anyone did it. Boards on the classroom wall are follow-through until then. Brief the teacher.

## 7. Card sets & worksheets

Full text, IDs, DE, facilitator notes, print spec: `[Card Deck v0.md](Card%20Deck%20v0.md)` — single source of truth.


| Set   | Name                           | Cards          | Placed by           | Mode                     |
| ----- | ------------------------------ | -------------- | ------------------- | ------------------------ |
| **A** | Layer sort                     | ~17 of 21 pool | Students            | Three rows per team      |
| **B** | Opinion cards                  | 10             | Students            | Continuum per team       |
| **S** | Starters (1 problem + 4 goals) | 5              | Facilitator / drawn | Left edge                |
| **C** | Mission 1 actions              | 14             | Students            | One shared A2            |
| **O** | Mission 1 endings (Oma)        | 6              | Facilitator         | Right edge, shared board |
| **D** | Mission 2 actions              | 18, two lots   | Students            | One A2 per team          |
| **H** | Mission 2 endings (Haushalt)   | 8              | Facilitator         | Right edge, each board   |
| **E** | Confidence statements          | 5              | Facilitator         | Wall / floor             |


Sets **S, O, H** are laminated reusables (no dots). Sets **C, D** are consumable (dots stick).

### Sheet F1 — Station A

- What is different between these two desktops? Name one thing each
- Find the games software on **Bazzite**
- How old is this laptop / what's inside? (`fastfetch`)
- Is anything being installed right now? *(No — runs from the stick)*
- What did this OS cost? *(Nothing)*

Mint = familiar. Bazzite = gaming / Steam Deck family. Let students hold a stick.

### Sheet F2 — Station B

- Something to play games with — and one game that launches
- Something to write a school report
- Something to edit video
- Something to draw or edit photos
- Something to play music or watch a film
- How old is this laptop, and what did it cost new?
- Something you already use every day
- What does all this software cost? *(Nothing)*

**When found:** most Steam titles work via Proton; some anti-cheat games still don't. LibreOffice / Office in browser; heavy macros are the exception.

## 9. Fallbacks and expansions


| If                      | Then                                                                                       |
| ----------------------- | ------------------------------------------------------------------------------------------ |
| 2 hours running clean   | Third distro at A → one-sentence gallery walk → Mission 2 longer → more opinion discussion |
| School offers 90 min    | Drop B3 + B11; primer 5 min; Mission 2 20 min, Lot 2 = three project cards only            |
| School offers 45–60 min | Decline or split across two sessions — do not cut Mission 2                                |
| One facilitator         | Guided whole-room hunt on B; single Mint boot for A during Mission 1 framing               |
| One laptop              | Keep Station A tasting; cover F2 myth-busts verbally                                       |
| Slow USB                | Pre-boot one distro; one live boot per group                                               |
| No partner near school  | Name nearest signed shop + CircularCity Map; say it's a tram ride                          |
| No network              | Assumed — everything offline                                                               |
| Deck not printed        | Short demo + Q&A + verbal missions + paper take-home; log the slip                         |
